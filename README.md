# EchoXeno

Analyzes network traffic and provides alerts for anomalies and security breaches in cloud infrastructure.

The key benefits of using EchoXeno include:

- Analyzes network traffic and provides
- alerts for anomalies and security
- breaches in cloud infrastructure

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EchoXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

EchoXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
